# GorevPanosu

Küçük bir ekip için görev panosu. Web uygulamasında yönetici görev oluşturur, düzenler, siler ve görevleri kişilere atar; tüm görevleri tablo halinde görür. Mobil uygulamada (iOS ve Android) çalışan yalnızca kendisine atanmış görevleri listeler, görevi tamamlandı olarak işaretler ve görev ayrıntısını görür; görev oluşturma mobilde yoktur. Web ve mobil aynı API'yi kullanır. Giriş sistemi gerekmez; kişi seçimi basit bir listeden yapılır.
